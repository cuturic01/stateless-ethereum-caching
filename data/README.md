# data/

Output of the block scraper (see `../block_scraper/`).

| file | tracked in git? | what it is |
|---|---|---|
| `manifest.json` | **yes** | run provenance: block range, shard size, schema version, and a sha256 for every shard |
| `checkpoint.json` | no (gitignored) | scraper resume state |
| `shards/*.msgpack.zst` | no (gitignored) | the actual block traces — gigabytes, regenerated by re-running the scraper |

Because the shards are not committed, a fresh clone will have the `manifest.json`
but no data; `scraper verify` will report the shard files as missing until you
re-run the scrape. The manifest documents exactly which dataset the experiments
used.
